# 📊 Marketing Campaign Performance Dashboard

## 🚀 Project Overview

The Marketing Campaign Performance Dashboard is a Business Intelligence project developed using Power BI to analyze and monitor the effectiveness of marketing campaigns across multiple digital channels.

This dashboard helps marketing teams, business leaders, and analysts evaluate campaign performance, optimize marketing spend, improve customer acquisition strategies, and maximize Return on Investment (ROI).

---

# 🎯 Project Objectives

The primary objectives of this project are:

* Analyze marketing campaign performance.
* Measure Return on Investment (ROI).
* Track customer acquisition effectiveness.
* Evaluate audience engagement.
* Identify top-performing campaigns.
* Optimize marketing budget allocation.
* Improve conversion performance.

# 📈 Key Performance Indicators (KPIs)

### Total Marketing Spend

Overall campaign investment.

### Total Revenue Generated

Revenue generated from campaigns.

### ROI %

Measures campaign profitability.

ROI = ((Revenue - Spend) / Spend) × 100

### CTR %

Measures ad engagement.

CTR = (Clicks / Impressions) × 100

### Conversion Rate %

Measures lead conversion efficiency.

Conversion Rate = (Conversions / Leads) × 100

### CPC

Cost Per Click.

### CPM

Cost Per 1000 Impressions.

### CAC

Customer Acquisition Cost.
